# Prakriti Storefront

A responsive frontend landing page for **Prakriti**, an Indian ethnic wear brand focused on Sambalpuri and Banarasi collections.

## Stack

- React + Vite
- React Router DOM
- Tailwind CSS
- Lucide React
- Swiper
- Framer Motion

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
